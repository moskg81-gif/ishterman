# Перед официальным запуском ИшТап

## 🔴 Обязательно: Firestore Security Rules

Сейчас Firestore работает в **test mode** — открытые правила.
Любой технически грамотный человек может читать и писать данные напрямую через консоль браузера, минуя приложение.

**Что нужно сделать перед запуском:**
- Зайти в Firebase Console → Firestore → Rules
- Настроить правила так чтобы только авторизованные пользователи могли писать свои данные
- Запретить чтение/запись чужих данных напрямую

Для тестирования с друзьями — текущий режим нормален и безопасен.
Но перед публичным запуском с большой аудиторией — обязательно закрыть.

- Vercel — надёжный хостинг, HTTPS автоматически
- Firebase Storage для аватаров — защищён
- Нет собственного бэкенда — нечего взламывать со стороны сервера
